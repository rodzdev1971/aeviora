| Authentication Process      | Secure login, strong passwords, MFA-ready structure                |
| Session Security Process    | Secure cookies, timeout, logout, token rotation                    |
| Authorization Process       | Verify every request before accessing PHI                          |
| Audit Logging Process       | Record who accessed, changed, exported, or deleted PHI             |
| Encryption Process          | Encrypt data in transit and at rest                                |
| Minimum Necessary Process   | Only show the minimum PHI needed for the task                      |
| Breach Response Process     | Detect, investigate, document, and notify when required            |
| Backup and Recovery Process | Encrypted backups and disaster recovery                            |
| Vendor BAA Process          | BAAs with hosting, email, SMS, storage, analytics, payment vendors |
| Staff Training Process      | Workforce HIPAA training and sanctions policy                      |
| Secure Development Process  | Code reviews, dependency scanning, vulnerability patching          |
